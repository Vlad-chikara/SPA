# Мій SPA-портфоліо

Це односторінковий додаток (SPA), створений з використанням React, який презентує мене як початківця-розробника.

## 🔗 Сторінки

- `/about` — Про мене та мої проєкти
- `/my-city` — Інформація про моє місто з поточною погодою
- `/my-future` — Мої плани та мотивація

## ⚙️ Технології

- React
- React Router DOM
- Axios
- OpenWeatherMap API
